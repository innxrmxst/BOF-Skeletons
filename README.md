This repository includes buffer overflow exploits and vulnerable applications for:

- 3com-tftp201 - TFTP server buffer overflow exploit
- brainpain - Stack-based buffer overflow practice
- SLMail-5.5 - POP3 PASS command remote buffer overflow
- vulnserver - Multi-vulnerability practice server for OSCP prep
- WarFTP-1.65-user-bof - FTP USER command remote buffer overflow
